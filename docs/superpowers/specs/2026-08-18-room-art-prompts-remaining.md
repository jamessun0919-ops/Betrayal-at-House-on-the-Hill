# 房間美術圖生成 Prompt 總表（剩餘 33 間，取代 2026-08-13 版本未生圖部分）

`data/rooms/rooms.json` 目前 49 筆房間裡，16 筆已有 `filename`（美術圖已完成），本文件涵蓋剩餘 33 筆尚未生圖的房間，取代 [2026-08-13-m2d3-room-art-prompts.md](2026-08-13-m2d3-room-art-prompts.md) 裡尚未生圖的部分（該文件其餘 16 間已生圖的內容仍然有效，不受影響）。

**本文件跟舊文件的差異**：
- 10 間房間（禮拜堂、塔橋、焦黑的房間、染血的房間、武器室、標本室、琴房、雜亂的房間、嬰兒房、舞廳）的 prompt 內容跟舊文件/設計文件完全相同（門型/門數沒有變動），直接沿用，方便集中在同一份文件生圖。
- 4 間房間（雕像長廊、廢棄的房間、傭人房、臥房）的房間資料在後續階段變動過（門數或 `doorPattern` 改變），舊文件的 prompt 已經跟現在的 `rooms.json` 對不上，本文件依**目前 `rooms.json` 的實際資料**重新設計，不沿用舊版。
- 19 間房間（`room_guest_1` 起）是後續內容稽核階段新增、從未寫過 prompt 的全新房間。
- 這 33 間裡，`doors:2` 且原本沒有 `doorPattern` 的房間，已依開發者指示統一補上 `doorPattern:"adjacent"`（`data/rooms/rooms.json` 已更新），本文件的門框配置依這個定案的門型撰寫。

**使用方式**：每張圖＝下方「固定風格區塊」逐字複製，接著貼上該房間的「本房間配置」＋「房間內裝潢」。四個牆面位置一律用「上/下/左/右」表示，實際門朝向哪個真實方位由渲染時旋轉決定，這裡的上下左右只是圖片內部的相對關係，不代表遊戲裡的絕對方向。

**門型變體規則回顧**：`doors:3` 房間只需 1 張圖（旋轉涵蓋所有方向，唯一實牆固定畫在「下」方）；`doors:4` 房間 1 張圖（四面都是門）。`doors:2` 房間依 `rooms.json` 的 `doorPattern`（`"opposite"` 或 `"adjacent"`）只需 1 張圖。`adjacent` 型房間本文件統一固定用「右、下兩面留門，上、左兩面實牆」的配置（跟舊文件的既有慣例一致，維持整套房間圖磚的視覺一致性）。

**總計**：`doors:2` 30 間＋`doors:3` 2 間＋`doors:4` 1 間＝ **33 張圖**。

## 固定風格區塊（每張圖逐字複用，跟先前版本相同）

```
1920年代鬼屋題材房間圖磚，完全正上方俯視角度（無透視傾斜、無立體景深，牆面畫成建築平面圖式的純平面線條），俯視遊戲地圖圖磚風格，手繪遊戲美術質感。四面牆body統一畫成較薄的規格（比獨立房間視覺合理厚度再薄一半，兩間房並列時兩片薄牆會加成正常厚度）。門框開口與大型家具的牆面配置，依下方【本房間配置】指示，未指定為門框的牆面一律畫成完整實牆。色調沉悶不飽和——暖棕色、褪色米色、灰塵灰、深色陰影。光線要平均、不要有明顯方向性。正方形 1:1 構圖，房間牆面直接頂到畫面四個邊緣，不留任何背景留白，只畫這一間房間，不要出現人物或怪物。這是一整套房間圖磚其中一張，鏡頭角度、牆面高度／厚度、門框位置與大小要維持固定，供整套房間套用同樣規格。
```
